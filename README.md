# DevSec-agent-didatico

*Especialização de agente que, em vez de responder direto, entende o contexto, avalia impacto, probabilidade e severidade e orienta a correção.*

Especialização introduz:

1. Uma skill nova em *skills/*, *vulnerability-analysis*, com o *SKILL.md* que o agente segue e um *README.md*;

2. Um arquivo em *agent/knowledge/*, como *security-basics.md*, com vulnerabilidade, ameaça, risco, a tríade confidencialidade, integridade e disponibilidade, e boas práticas;

3. Um trecho no *agent/persona.md* e uma linha na tabela de skills do *AGENTS.md*, para o agente saber quando usar a skill.
